# Throughline Benchmark Plan

Status: **planned; no efficacy result has been published**.

## Question

Does Throughline preserve more supported meaning in a smaller durable work
artifact while helping an independent reader understand the promise, open
decision, and restoring condition?

## Corpus

Each frozen source packet needs an adjudicated inventory of:

- requested capabilities and constraints;
- concrete examples and counterexamples;
- uncertainty and unresolved questions;
- prohibited or unsupported claims;
- parent and child promises;
- enabling actions that are not themselves the user value; and
- the integrated reality-based Witness needed for closeout.

The first corpus should include at least one software planning packet and one
non-engineering packet. Protected material must not enter a public
fixture.

## Arms

1. The same agent with no intent-shaping skill.
2. The same agent with a generic instruction to be concise and preserve intent.
3. The same agent with Throughline.
4. One separately pinned reductive-compression control, required once its
   version, license, promise, and invocation are made comparable.

Every arm must use the same source packet, model, effort, tools, starting state,
time budget, and output request. Order and fresh-session effects must be
recorded.

## Fidelity Gate

An output fails before any compression score when it:

- loses an adjudicated requirement, constraint, example, counterexample,
  uncertainty, or prohibited-claim boundary;
- invents intent not supported by the source packet;
- substitutes implementation work for the promised capability;
- lets child completion stand in for the parent's integrated Witness; or
- hides a contradicting unresolved Mystery while presenting the Story as
  complete.

Adjudicators must map every output claim back to the frozen packet. Disagreement
and resolution are part of the raw record.

## Primary Measures

For fidelity-passing outputs only, report:

- supported inventory items retained per 1,000 output tokens;
- percentage of the adjudicated meaning inventory retained;
- invented or unsupported additions;
- blinded-reader identification of the promised reality;
- blinded-reader identification of the open decision or uncertainty;
- blinded-reader identification of the restoring Witness; and
- reader comprehension time.

Token density without complete meaning retention is a failure, not a gain.

## Secondary Measures

Record turns, input and output tokens, provider cost when available, elapsed
time, clarification requests, scope drift, false parent closure, and human
rescue. These are descriptive unless the experimental design supports a causal
claim.

## Publication Gate

No percentage, savings claim, or comparison chart may appear in the README
until this directory contains:

- versioned source packets and adjudicated meaning inventories;
- machine-readable raw outputs and scoring decisions;
- scoring and token-counting code;
- the blinded-reader protocol and anonymized responses;
- reproduction instructions;
- model, effort, host, tool, and artifact provenance; and
- an independent verification of the reported aggregation.

The README placeholder is the only approved evidence panel until that gate
passes.
